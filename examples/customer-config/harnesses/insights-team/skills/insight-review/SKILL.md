# Insight review checklist

Check each item. When an item needs a change, fix the draft and write one short note.

1. **Grounded**: every figure in the answer appears in the statistics. Remove or correct any figure
   that does not.
2. **Sample size**: say so when a group or column has fewer than five values.
3. **Spread**: when the standard deviation is more than 25% of the mean, call the series highly
   variable.
4. **Outliers**: note a value that is far outside the range of the other values in its group.
5. **Missing data**: mention columns where null or non-numeric cells were skipped.
6. **No causal claims**: replace "because" or "caused by" with neutral wording unless the data
   shows the cause.

The verdict is `approved` only when no item needed a change; otherwise it is `revised`.
